# **App Name**: AssessWell

## Core Features:

- Call-to-Action Buttons: Two clearly labeled buttons: 'Self-Assessment' and 'Assess Someone Else'.
- Descriptive Sections: Informative sections detailing the purpose and benefits of each assessment type.
- Clean Layout: Visually appealing layout with clear distinction between sections.

## Style Guidelines:

- Primary color: A calming blue (#3498db) to inspire confidence.
- Secondary color: A neutral gray (#ecf0f1) for backgrounds and subtle elements.
- Accent: Green (#2ecc71) for positive reinforcement and call-to-action highlights.
- Use a grid-based layout for a structured and professional look.
- Use subtle icons to enhance the visual appeal of the page.
- Gentle transitions and hover effects for a smooth user experience.
